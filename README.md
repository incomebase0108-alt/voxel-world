# VOXEL WORLD

ブラウザで動くマインクラフト風ボクセルゲーム（試作）。
Three.js 製・HTML 1枚で動作。キャラクターは Blender 製 GLB を差し替えて使う。

## 遊び方
`index.html` をブラウザで開く →「クリックして開始」。

- `W` `A` `S` `D` 移動 / `Shift` ダッシュ / `Space` ジャンプ
- マウス 視点 / 左クリック ブロック破壊 / 右クリック 設置
- `1`〜`6` 設置ブロック選択 / `Esc` 一時停止

## 現状（v1 / 1号機）
- 一人称移動・重力・当たり判定
- マイクラ風の無限自動生成地形（草/土/石/砂/木）＋チャンク動的ロード
- ブロック破壊・設置

## ロードマップ（分担）

### 1号機（エンジン／ゲームプレイ）
- [ ] バイオーム拡張（水・砂漠・雪など）
- [ ] インベントリ／ホットバー拡充
- [ ] 昼夜サイクル・簡易ライティング
- [ ] ワールドのセーブ／ロード（localStorage）
- [ ] GLB キャラの読み込み口（プレイヤー／モブ）

### 4号機（Blender キャラ造形）
- [ ] プレイヤーキャラの造形 → `models/player.glb`
- [ ] モブ数体の造形 → `models/*.glb`
- [ ] 顔パーツ・髪・筋肉まで作り込む（ブロック調は避ける）
- [ ] 書き出しは glTF Binary (.glb)、Y-up、1ブロック≒1m スケール目安

## ディレクトリ
```
index.html      ... ゲーム本体（エンジン）
models/         ... Blender 製 GLB を置く（4号機）
models/ASSETS.md   ... 全アセット索引（ファイル/クリップ/容量・自動生成）
models/ASSETS.json ... 同・機械可読版（1号機/3号機が参照）
models/LAYOUT.md   ... 構造物の配置仕様シート（1号機②自動生成の見本・グリッド座標）
models/EQUIP_HOLD.md ... 装備の手持ち表示仕様（手アンカー・グリップ角度）
models/BLOCKS_PROPOSAL.md ... 装飾ブロック案（マテリアル値・エンジン流用）
models/ORES.md     ... 鉱石ブロック/洞窟装飾の採掘ランク・ドロップ・配置仕様
tools/icons/       ... インベントリ/ホットバー用アイコン（icons.json/ICONS.md）
README.md       ... この文書（兼・作業ブリーフ）
```
