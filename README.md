# VOXEL WORLD

ブラウザで動くマインクラフト風ボクセルゲーム（試作）。
Three.js 製・HTML 1枚で動作。キャラクターは Blender 製 GLB を差し替えて使う。

## 遊び方
`index.html` をブラウザで開く →「クリックして開始」。

- `W` `A` `S` `D` 移動 / `Shift` ダッシュ / `Space` ジャンプ
- マウス 視点 / 左クリック ブロック破壊 / 右クリック 設置
- `1`〜`6` 設置ブロック選択 / `Esc` 一時停止
- `P` ペット（チンチラ「さくら」）を なでる／餌をあげる・近くの動物をなつかせる

## 主人公もチンチラ🐭
- プレイヤーキャラはチンチラ。タイトルの「キャラクター選択」で**8色**（標準/ベージュ/ホワイト/エボニー/バイオレット/サファイア/ブラウン/ピンク）から選べる（選択は保存）。
- 三人称（`F`）だと**ぴょこぴょこ歩く大きめチンチラ**。武器の手持ち表示は腕ボーンが無いので非表示（戦闘・採掘はそのまま動作）。

## ペット🐾（チンチラ）
- 起動すると相棒のチンチラ「さくら」がついてくる（写真準拠の専用モデル `models/pet_chinchilla.glb`）。
- **機嫌**（ごきげん／ふつう／ごきげんななめ）が、そばにいる・餌・なでるで上がり、放置・空腹・恐怖で下がる。
- **癖（性格）**：やんちゃ／なまけ／甘えん坊／食いしん坊／びびり／つんでれ で、追従距離・速さ・仕草が変わる。
- 機嫌が良いと**ぴょこぴょこ弾んで尻尾を振り**、ハートを出す。不機嫌だと**そっぽを向いて拗ねる**。
- **怒る系の行動**（チンチラの十八番）：
  - 近くに敵モブがいると **噛みつく**（少し助太刀ダメージ）／**立っておしっこを飛ばす**（敵を威嚇）。
  - 機嫌が「ごきげんななめ」だと、プレイヤーに **八つ当たり**（噛みつき／立ちオシッコ／プンプン震える）。
  - 機嫌が最悪の時に `P` でなでようとすると **噛みつく**（つんでれ）。おしっこは近いと一瞬スリップ。
- **同名つながり**：最終ボス「巨大チンチラの女王**さくら**」を察知すると、ペットのさくらが**毛を逆立てて身構え**、近づきすぎず**遠目から立ちオシッコ／プンプンで威嚇**する（同名でも懐かない）。
- **色違いチンチラだらけの世界**：野生のチンチラが8色（ベージュ／グレー／ホワイト／エボニー／バイオレット／サファイア／ブラウン／ピンクホワイト）で大量に湧く（中立動物・地上湧きの約85%）。`P`＋餌でどれもなつかせOK（最大4匹コレクション）。
- モデル生成: `python3 tools/build_pet_chinchilla.py`（Blender不要・標準ライブラリのみ／8色GLB＋プレビューPNG＋カラー一覧を出力）。

## ロードマップ（分担）

### 1号機（エンジン／ゲームプレイ）
- [ ] バイオーム拡張（水・砂漠・雪など）
- [ ] インベントリ／ホットバー拡充
- [ ] 昼夜サイクル・簡易ライティング
- [ ] ワールドのセーブ／ロード（localStorage）
- [ ] GLB キャラの読み込み口（プレイヤー／モブ）

### 4号機（Blender キャラ造形）
- [ ] プレイヤーキャラの造形 → `models/player.glb`
- [ ] モブ数体の造形 → `models/*.glb`
- [ ] 顔パーツ・髪・筋肉まで作り込む（ブロック調は避ける）
- [ ] 書き出しは glTF Binary (.glb)、Y-up、1ブロック≒1m スケール目安

## ディレクトリ
```
index.html      ... ゲーム本体（エンジン）
models/         ... Blender 製 GLB を置く（4号機）
models/ASSETS.md   ... 全アセット索引（ファイル/クリップ/容量・自動生成）
models/ASSETS.json ... 同・機械可読版（1号機/3号機が参照）
models/LAYOUT.md   ... 構造物の配置仕様シート（1号機②自動生成の見本・グリッド座標）
models/EQUIP_HOLD.md ... 装備の手持ち表示仕様（手アンカー・グリップ角度）
models/BLOCKS_PROPOSAL.md ... 装飾ブロック案（マテリアル値・エンジン流用）
models/ORES.md     ... 鉱石ブロック/洞窟装飾の採掘ランク・ドロップ・配置仕様
models/SHIPS.md    ... 船モデルの乗船位置(甲板/喫水線)・配置仕様
tools/icons/       ... インベントリ/ホットバー用アイコン（icons.json/ICONS.md）
README.md       ... この文書（兼・作業ブリーフ）
```
