# VOXEL WORLD 装備の手持ち表示 仕様（1号機の装備システム向け）

剣/ピッケル/斧/弓/盾を **player.glb の手にどう持たせるか**（手のアンカー・グリップ角度）。
見本レンダ → `tools/hold_sword_*.png` / `hold_pickaxe_*` / `hold_axe_*` / `hold_bow_*` / `hold_hero_*`（剣＋盾）。
再現/再レンダは `tools/build_hold_demo.py`（`HOLD` 辞書を編集）。

---

## 0. 前提（装備側はもう手持ち対応済み）

- 各 `item_*` の **origin＝握り**（`ASSETS.md` 参照）：剣/ピッケル/斧＝柄基部、弓＝握り中央、盾＝中心。
  → **origin を手のアンカーに合わせて置き、軽く回すだけ**で持てる。
- player.glb のノード階層：`Body > {ArmL, ArmR, LegL, LegR}`（armature不使用・各腕は独立ノード）。
  武器は **対応する腕ノードの子に付ける**とアニメ（idle/walk/attack）に追従する。

## 1. 手のアンカー位置（restポーズ・実測）

※2026-06-02 ヒーロー作り込み版 player.glb で再計測（籠手/グローブ反映）。

| | Blenderワールド(m, Z-up,+Y正面) | エンジン(glTF Y-up, -Z正面) |
|---|---|---|
| 右手 HAND_R | (-0.37, 0.0, 0.73) | (-0.37, 0.73, 0.0) |
| 左手 HAND_L | ( 0.37, 0.0, 0.73) | ( 0.37, 0.73, 0.0) |

参考：肩ピボット（腕ノード原点）は右 ArmR=(-0.30,0,1.47)／左 ArmL=(0.30,0,1.47)（Blender m）。
→ 手は肩から約 0.74m 下。腕ノードの子に付ける場合のローカル位置 ≒ `HAND - 肩`。
ヒーロー版は鋼の籠手/グローブを装着済み＝武器を握る手元が映える。見本 `tools/hold_hero_front.png`（盾＋剣）。

## 2. 武器別グリップ（位置は手アンカー基準・回転は軽い微調整）

| 武器 | 持ち手 | 位置(手から) | 回転(度) | 向き |
|---|---|---|---|---|
| `item_sword` | 右 | +0 | X **-18** | 刃を上・やや前へ |
| `item_pickaxe` | 右 | +0 | X **-12** | 頭を上・やや前へ |
| `item_axe` | 右 | +0 | X **-12** | 斧頭を上・やや前へ |
| `item_bow` | 左 | +(0, 0.04, 0.05)※ | X **+8** | 弓を縦・握り中央を手に |
| `item_shield` | 左 | +(0.02, 0.16, 0.32)※ | 0 | 左前腕に・正面(-Z)外向き |

※位置オフセットは Blender(X,Y,Z) m。回転 X は両座標系で同符号（X軸共通）。**最終調整は1号機の実機で**（腕の rest 角度・スケールにより数度ずれる）。

## 3. 1号機向け実装メモ

- 最小実装：武器シーンノードを **対応腕ノードの子**にして `position = (HAND - 肩)`、`rotation.x` を上表の値に。
- 抜き持ち/納刀：武器ノードの visible を切替、または背中/腰アンカー（背：`(0, 1.2, -0.18)` 付近 glTF）へ移すと収納表現。
- 攻撃モーション：剣/斧は player の `attack` クリップ（腕が振られる）に武器が追従＝腕の子なら自動。弓は別途「引き絞り」を将来追加可（要望あれば4号機で bow に `draw` クリップを内包）。
- 盾は左腕の子。`block` 演出は左腕を前に出す簡易回転で可（モデル追加不要）。
- スケール注意：player.glb は内部ノード単位に Body スケールが乗る（肩ノード Y=4.867→world1.46m＝係数≈0.30）。**ワールド配置なら上のm値をそのまま**、腕ノードのローカル子にするならその座標系（スケール込み）に変換のこと。
