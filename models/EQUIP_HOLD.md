# VOXEL WORLD 装備の装着基準（数値確定版・1号機の装備システム向け）

剣 / 斧 / ピッケル / 弓 / 盾を **player.glb の手にどう持たせるか**の確定値。
実機で「剣が背中に刺さる／盾が腕の裏に回る」不具合の根治を含む。**この表の数値をそのまま使えば持てる。**
見本レンダ：`tools/hold_hero_front.png` `tools/hold_hero_3q.png`（剣＋盾の決定版）、`hold_sword_*` `hold_pickaxe_*` `hold_axe_*` `hold_bow_*`。
再現は `tools/build_hold_demo.py`（`HOLD` 辞書）。装備モデルは `tools/build_equipment.py`。

> 2026-06-04 改訂（4号機）。旧版からの変更点（実機不具合の原因2つを潰した）：
> 1. **剣 / 斧 / ピッケルの glb 原点を「柄の最下端」→「握り」に移動**（再ビルド済み）。
>    旧原点は柄頭にあり、手に付けると 95cm の刀身が拳の根元から生え、回転で先端が大きく振れた＝「背中に刺さる」。
> 2. **player.glb の腕ノードは非一様スケールを持つ**（後述）。武器を腕ノードへ直接子付けすると
>    せん断歪みで向きが狂う。**ワールド追従方式**を推奨（§3）。

## 0. 座標系（必読）

- **エンジン（glTF / three.js）**：右手系・**+Y=上 / −Z=前（プレイヤー正面・敵方向）/ +X=プレイヤーの左**。
- **Blender（造形側）**：Z-up・正面=+Y。エクスポートは `export_yup=True`。
  - 位置変換：glTF(x, y, z) = Blender(x, z, −y)
  - X軸回りの回転は**両座標系で同符号・同軸**（Blender +X = glTF +X）。本書の回転は glTF 基準だが Blender でも同値。
- 1ブロック ≒ 1m。以降の数値はすべて **glTF・メートル**。

## 1. プレイヤーの手・肩（player.glb 実測・glTF）

ノード階層：`Body >（子）ArmL / ArmR / LegL / LegR`（armature不使用・各腕は独立ノード）。
中立姿勢（腕を真下）での実測ワールド座標：

| 部位 | アタッチ先ノード | ワールド位置(glTF) | 備考 |
|---|---|---|---|
| 右手 HAND_R | `ArmR` | **(−0.43, 0.72, 0.00)** | 剣 / 斧 / ピッケル |
| 左手 HAND_L | `ArmL` | **(+0.43, 0.72, 0.00)** | 弓 / 盾 |
| 右肩ピボット | `ArmR` 原点 | (−0.30, 1.46, 0.00) | 腕の回転中心 |
| 左肩ピボット | `ArmL` 原点 | (+0.30, 1.46, 0.00) | 腕の回転中心 |

- 手は肩から **約 0.74m 真下**（中立）。腕は肩ピボットを中心に X 回転（idle ≒+22°/+13°、attack は大振り）。
- idle 中はこの回転で手が前(−Z)へ約0.28m振れる。装着は**手ノードのワールド変換を毎フレーム参照**すれば自動追従する（§3）。

## 2. 各装備の glb 原点（再ビルド済み・glTF）

「原点＝1号機が手に合わせる基準点」。**原点を手アンカーに置けば握り点が拳に来る**。

| 装備 | 原点(=握り/中心) | Y方向の張り出し（原点=Y0基準） | 形状の前面 |
|---|---|---|---|
| `item_sword` | 握り中央（鍔のすぐ下） | 柄頭 Y=−0.165 / 刃先 Y=+0.827 | 刃は +Y（後で前へ倒す） |
| `item_pickaxe` | 握り | 柄尻 Y=−0.140 / 頭 Y=+0.62 | 頭は +Y 上端・横長(±0.43) |
| `item_axe` | 握り | 柄尻 Y=−0.140 / 頭 Y=+0.67 | 斧身は +X 側・頭は +Y 上端 |
| `item_bow` | 握り中央 | 上下対称 Y=±0.52 | 弓の腹＝−Z(前)・弦＝+Z(射手側) |
| `item_shield` | 形状中心 | 上下対称 Y=±0.40 | **表面(ボス/板目)＝−Z(前)** ✓ |

> **盾は向きが正しい**（モデルの表面は −Z＝前を向く）。「腕の裏に回る」のはモデルではなく**装着側の符号ミス**。§4 の通り **Z オフセットを −0.16（前）にし、Y回転 0（180°反転しない）** で表に来る。

## 3. 装着方式（推奨：ワールド追従・せん断回避）

**player.glb の腕ノードは非一様スケールを持つ**（`Body S=[0.30,0.30,0.17]` × `Arm S=[0.333,0.367,0.647]`）。
このため武器を腕ノードへ**直接子付けすると非一様スケールが乗ってせん断歪み**を起こし、向き・形が崩れる
（実機の「刺さる／裏に回る」のもう一つの主因）。回避するため、武器は **シーン直下に置き、毎フレーム手の
ワールド変換だけを写して配置**する（武器のワールド scale は常に 1.0＝実寸）。

```js
// 初期化：weapon はシーン直下に追加。weapon.scale=(1,1,1)。
// 毎フレーム：
armNode.updateWorldMatrix(true, false);
const handWorld = HAND_LOCAL.clone().applyMatrix4(armNode.matrixWorld); // §1の手ワールド点
const armQuat   = new THREE.Quaternion();
armNode.getWorldQuaternion(armQuat);            // 腕の回転(attack大振りも含む)を継承＝自動追従
weapon.position.copy(handWorld).add(OFFSET);    // OFFSET=§4(手アンカーからの微調整)
weapon.quaternion.copy(armQuat).multiply(GRIP); // GRIP=§4の初期回転(euler→quat)
// ※ getWorldQuaternion は scale を無視＝歪みを持ち込まない
```

- これで **idle/walk の腕振り・attack の大振りに武器が追従**（剣は手の回転で前へ振り抜く）。
- 既存の `getHeldDebug()`（sword/shield の world pos/up/front）はこの方式の検証に使える。
- 抜き持ち/納刀：weapon.visible 切替、または収納アンカー 背 `(0, 1.2, −0.18)` / 腰へ移す。

> どうしても子付け運用を続ける場合は、武器ノードのローカル scale で腕のワールドスケールを打ち消すこと
> （非一様なので歪みが残る。**非推奨**）。新方式へ移行を推奨。

## 4. 装着数値表（③・1号機がそのまま使う確定値）

| 装備 | アタッチ先 | 位置オフセット(x,y,z) glTF・m | 初期回転 euler(X,Y,Z)° | グリップ原点 |
|---|---|---|---|---|
| `item_sword`   | HAND_R / `ArmR` | (0, 0, 0)            | **(−18, 0, 0)** | 握り中央（刃が +Y→前上へ−18°倒す） |
| `item_pickaxe` | HAND_R / `ArmR` | (0, 0, 0)            | **(−12, 0, 0)** | 握り（頭が上前方） |
| `item_axe`     | HAND_R / `ArmR` | (0, 0, 0)            | **(−12, 0, 0)** | 握り（斧頭が上前方） |
| `item_bow`     | HAND_L / `ArmL` | (0, +0.05, −0.04)   | **(+8, 0, 0)**  | 握り中央（弓を縦・腹を前） |
| `item_shield`  | HAND_L / `ArmL` | **(+0.02, +0.32, −0.16)** | **(0, 0, 0)** | 中心（表面=−Z 前。**Z=−0.16で前へ・180°反転禁止**） |

- **位置オフセット**＝§1の手アンカー（HAND_R/L のワールド点）からの微調整。剣/斧/ピッケルは原点が握りなので追加0。
- **初期回転**＝GRIP（手の回転に掛ける）。剣の刃は元 +Y(上)。X=−18° で −Z(前)へ倒れ「前上向き」になる。
  X を負に増やすほど前へ寝る（−90°で真正面）。背中(+Z)へ向く場合は**符号が逆**＝+18 を入れている。
- **盾**：オフセット Z=**−0.16（前/−Z）**が要。+0.16 や Y=180° を入れると腕の裏へ回る。Y回転は 0 のまま。
