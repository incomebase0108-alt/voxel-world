# VOXEL WORLD 構造物 配置仕様シート（1号機②自動生成 向け）

`struct_*.glb` を村/ダンジョンの自動生成でどう組み立てるかの**寸法・グリッド座標つき見本**。
実パーツを実際に組んだ見本レンダ → `tools/layout_cottage.png` / `tools/layout_dungeon.png` / `tools/layout_overview.png`。
この表の座標は見本ビルド `tools/build_layout_demo.py` の `place(...)` と一致（＝仕様の実体）。

---

## 0. グリッド規約（全構造物共通）

- **1セル = 1m**（`1ブロック≒1m` に一致）。
- **配置基準点（ノード原点）= 構造物フットプリントの中心・床（地面 y=0）**。
  → 1号機はセル中心の地面に origin を置くだけでよい（足元が地面に乗る）。
- **正面（装飾面）= モデルの -Z（glTF）**。窓のガラス面・ドアの取手・壁の板目・盾紋章などが -Z 側。
- **yaw（Y軸まわり・度・CCW）で正面の向きを回す**：

  | yaw | 正面の向き | 用途（家のどの壁か） |
  |---|---|---|
  | `0`   | +Z（北） | 北壁 |
  | `90`  | -X（西） | 西壁 |
  | `180` | -Z（南） | 南壁（手前） |
  | `270` | +X（東） | 東壁 |

- 座標表記：`(X, Z)` = 水平グリッド、`level` = 段（1段=1m、`y = level × 1.0`）。

## 1. パーツ別フットプリントと積み方

| モデル | 寸法(m) X×Z×Y | 占有 | 積み/置き方 |
|---|---|---|---|
| `struct_wall` | 1.0×0.9×1.0 | 1セル・1段 | 壁面に沿って並べ、yawで外向き。縦に積めば多段壁（level0,1,2…） |
| `struct_window`| 1.0×0.16×1.0 | 1セル・1段 | 壁の1セルを窓に置換（上段level1推奨＝採光） |
| `struct_door` | 0.9×0.26×**2.0** | 1セル・**2段ぶん** | level0 に置くと上へ2m伸びる。同セルの level0/1 に壁を置かない |
| `struct_roof` | 1.0×1.0×1.0(勾配) | 1セル | 勾配片。高い側が棟、低い側が軒。Y方向スケールで1枚葺き可（後述） |
| `struct_fence` | 1.0×0.17×1.0 | 1セル幅 | 生垣/庭の囲い。yawで向き |
| `struct_well` | 2.0×2.0×2.46 | **2×2セル** | origin=2×2の中心。単独設置（庭・広場） |

## 2. 見本：5×5 コテージ（`layout_cottage.png`）

フットプリント X∈0..4, Z∈0..4。壁2段（level0/1）、屋根 level2。南(Z=0)が正面。

### 壁（`struct_wall`）
| 壁 | セル | level | yaw |
|---|---|---|---|
| 南 | (0,0)(1,0)(3,0)(4,0) | 0 | 180 |
| 南 | (0,0)(4,0) | 1 | 180 |
| 北 | (0,4)(1,4)(2,4)(3,4)(4,4) | 0 | 0 |
| 北 | (0,4)(1,4)(3,4)(4,4) | 1 | 0 |
| 西 | (0,1)(0,2)(0,3) | 0,1 | 90 |
| 東 | (4,1)(4,2)(4,3) | 0,1 | 270 |

### 開口（ドア・窓）
| 種別 | セル | level | yaw | 備考 |
|---|---|---|---|---|
| `struct_door` | (2,0) | 0 | 180 | 南の中央。2m＝level0/1を占有（その2セルに壁なし） |
| `struct_window` | (1,0)(3,0) | 1 | 180 | 南上段。下段(level0)は壁 |
| `struct_window` | (2,4) | 1 | 0 | 北上段 |

### 屋根（`struct_roof`・棟は東西方向）
各 X 列に2枚、Y方向2倍スケールで南北の各面を1枚葺き：
| 面 | セル(中心) | level | yaw | scale |
|---|---|---|---|---|
| 南面 | (x, 1.0) for x=0..4 | 2.0 | 180 | (1, 2, 1) |
| 北面 | (x, 3.0) for x=0..4 | 2.0 | 0 | (1, 2, 1) |

> 補足：屋根は voxel 流に**段葺き（roof piece を階段状に積む）**でも可。1枚葺きが嫌なら各面を level2→2.5 と1mずつ上げながら棟へ寄せる。1号機の実装都合で選択可。

### 庭（任意）
- `struct_well` を広場中心に1個（例 中心 `(7.5, 2.0)`）。2×2セルを確保。
- `struct_fence` を生垣に並べる（例 南辺 `(6,-1)(7,-1)(8,-1)(9,-1)` yaw0、西辺 `(5.5,0)(5.5,1)(5.5,2)` yaw90）。

### 村への展開
- コテージを 1ユニットとして 8〜12セル間隔で複製・回転（yawオフセット）して点在。
- 道は地形ブロック側で。井戸は村の中心に1つ、柵で各戸の庭を囲う。

## 3. 見本：ダンジョン部屋（`layout_dungeon.png`）

7×7 の石室を想定（X∈12..18, Z∈0..6、中心 X=15, Z=3）。標準レイアウト：

| 要素 | モデル | セル | yaw | 役割 |
|---|---|---|---|---|
| スポナー | `struct_spawner` | (15, 3) | 0 | 部屋中央。湧き点 |
| 宝箱（手前） | `struct_chest` | (12.5, 0.6) | 0 | 入口寄り報酬 |
| 宝箱（奥） | `struct_chest` | (17.5, 5.4) | 200 | 隠し報酬（少し振る） |
| 祭壇 | `struct_altar` | (15, 5.6) | 0 | 奥のボス/ギミック |
| 松明 ×4 | `struct_torch` | (12,1)(12,5)(18,1)(18,5) | 90/90/270/270 | 四隅の壁付近・照明 |

レイアウト原則：
- **スポナーは中央・四方に逃げ場**（プレイヤーが捌けるよう周囲1.5セル空ける）。
- **宝箱は対角**に散らし、奥は祭壇とセットでボス部屋感。
- **松明は壁に沿って**（yawで壁向き）、明暗で誘導。
- 宝箱は `open` クリップを順再生で開／逆再生で閉（rest=閉）。スポナー/松明/祭壇は `idle` を常時再生。

## 4. 1号機向け実装メモ

- 配置は **origin をセル中心の地面に置く → yaw を Y軸回転 → 必要なら多段は level×1m で上積み**、これだけ。
- 全 `struct_*` は足元 z=0・装飾面 -Z で統一済み（`ASSETS.md` 参照）。`struct_door` のみ高さ2m＝2段ぶん。
- 当たり判定は各モデルの寸法（`ASSETS.json` の `size` 相当）で AABB を取れば十分。ガラス窓は描画半透明・衝突あり（既存ガラスブロックと同方針）。
- 見本シーンを変えたい時は `tools/build_layout_demo.py` の `HOUSE`/ダンジョン配列を編集して再レンダ。
